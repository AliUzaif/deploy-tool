Deploy Tool Setup Guide
-----------------------

This guide explains how to set up the Deploy Tool and its Monitoring infrastructure using Terraform.

Prerequisites
-------------
Before starting, make sure you have the following installed and configured:
- Terraform (v1.0+ recommended)
- AWS CLI configured with valid credentials
- Access to the repository containing this project

1. Setup Infrastructure for the Deploy Tool (excluding monitoring)
------------------------------------------------------------------
1. Navigate to the "terraform" folder in the root directory:
   cd terraform

2. Run the following commands:
   terraform init
   terraform plan
   terraform apply

This will provision the core infrastructure for the Deploy Tool.

2. Setup Monitoring Infrastructure
----------------------------------
1. Navigate to the "monitoring/terraform" directory:
   cd monitoring/terraform

2. Run the following commands:
   terraform init
   terraform plan
   terraform apply

This will provision the monitoring instance.

3. Once the instance is up:
   - SSH into the monitoring instance:
     ssh -i <your-key>.pem ubuntu@<instance-public-ip>

   - Copy/save the required files, maintaining the same structure as in the "monitoring" directory (as mentioned in the documentation).

--------------------------------------------------------------
You have now successfully set up both the Deploy Tool and its Monitoring infrastructure.
